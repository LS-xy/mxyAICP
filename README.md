# mxyA · 站点标识项目

一个自建的「仿备案标识」小站：申请一个编号、拿到一枚页脚徽标、放在自己网站底部。
纯 PHP + MySQL，无需框架、无需构建，上传即用。

- 演示站：<https://icp.imxy.cn>
- 官方群：<https://qm.qq.com/q/IcCR2VZQUW>

> 本站是娱乐性质的站点标识项目，不具备任何官方备案效力，不能替代工信部 ICP 备案。

---

## 功能

**公开页**

- 首页：查询编号 / 网址，公告以弹窗形式展示
- 申请：一张表单搞定，图形验证码 + 邮箱验证码，发码走 AJAX 不刷新页面
- 查询：展示编号的详细信息，并生成可直接粘贴的页脚代码
- 页脚：内置多套页脚样式，点击样式 → 输入编号 → 生成代码；访客也可以上传自己的样式

**后台**

- 审核：通过 / 拒绝申请
- 站点：查看所有已收录站点
- 设置：站点名称、公告、通知邮箱、公开字段、编号前缀、邮件模式
- 徽标：上传页脚图标、设置徽标文字与圆点颜色
- 页脚：审核访客上传的页脚样式
- 邮箱 / 管理员（仅 owner 角色可见）

**界面**

- 纯白简约风，三套主题：浅色 / 深色 / 暖色，跟随 localStorage
- 导航是右下角悬浮气泡，点开从右侧滑出抽屉（内联 SVG 图标，无 emoji）
- 输入框是 Material 式描边缺口：标签在框内，聚焦后上浮到边框线上，边框按文字长度断开

## 安装

1. 把全部文件上传到网站根目录（PHP 8.0+，MySQL 5.7+）。
2. 确保根目录和 `inc/`、`admin/`、`admin/inc/`、`assets/` 可写。
3. 打开 `/loading.php`，按向导填写数据库、管理员账号、SMTP。
4. 安装完成后 `install.lock` 生成，`loading.php` **会自动删除**（删除失败时页面会提示手动删除）。
5. 用安装时创建的账号登录 `/admin/login.php`。

### 安装后建议

- 后台 → 设置 → **通知邮箱**：新申请、新页脚会发到这个地址；留空则自动用第一个发件邮箱。
- 后台 → 设置 → **公告**：填写后首页自动弹窗，点空白处或「知道了」关闭。
- 后台 → 徽标：上传自己的页脚图标（png / svg / webp，≤512KB）。

## 页脚上传规则

访客上传的页脚会先进入待审核队列，管理员通过后才会出现在公开页。

- 只收 HTML + 内联 CSS 片段，不接受 `<script>`、`<iframe>`、`<form>`
- 不接受外链资源（图片请转 data URI）
- 不接受 `on*` 事件属性
- 单个片段 ≤ 20KB，≤ 60 行
- 片段中用 `__CODE__` 和 `__LINK__` 作占位符，生成代码时自动替换成编号和详情页链接

服务端会对上传内容二次清洗：删除脚本类标签、事件属性、`javascript:` 协议与外链引用。

## 编号规则

`前缀-年份-后缀`，例如 `MOE-2026-7XK`。

- 前缀在后台「设置」里改（默认 `MOE`）
- 年份取申请时的年份
- 后缀由申请人填，2–8 位字母或数字，提交时自动转大写并检查是否已被占用

## 安全与限制

- 所有写操作校验 CSRF token
- 发验证码需要图形验证码；**同一邮箱、同一 IP 5 分钟内只能发一次**，另有每小时 / 每天的兜底上限
- 验证码 10 分钟有效，一次使用后置为已用
- 页脚内容存库前清洗，前端不执行任何用户脚本
- 后台密码用 `password_hash()` 存储

## 常见问题

**Q：点「返回首页」404？**
本站所有入口都是 `/index.php` 这种带文件名的形式，避免 CDN 对 `/` 的缓存差异。

**Q：改了样式不生效？**
`style.css` / `app.js` 用 `?v=yyyyMMdd` 版本号做缓存控制，改完把版本号 +1 即可。

**Q：验证码邮件发不出去？**
后台 → 邮箱，确认 SMTP 主机、端口、加密方式（SSL 465 / TLS 587）与授权码正确；QQ 邮箱要用授权码而不是登录密码。
